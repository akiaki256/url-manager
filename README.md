# URL管理ツール

よく使うURLを、タイル状のアイコンで視覚的に管理できるスタートページ（Webアプリ）です。

## 概要

既存のブラウザのブックマークやスタートページの見た目・使い勝手を自分好みにしたい、という思いから制作しました。

登録したURLをタイルとして一覧表示することで、ファイル構造ではなく画面の位置関係としてURLを管理することが可能です。

各タイルには名前・メモ・ファビコンを設定でき、データはブラウザのローカルストレージに保存されるため、再訪時も登録内容が保持されます。

「シンプルでモダンなUI」を目指し、スタートページに求められる機能は実装しつつ過剰な機能・装飾は避けています。

HTML / CSS / JavaScript の学習を兼ねて、実際に自分が使いたいものを形にすることを目標に開発しました。

## 主な機能

- **タイル形式での一覧表示** … 登録したURLをタイルとして並べて表示。ドラッグ&ドロップでタイルの位置を自由に並び替え可能
- **URLの登録・編集** … URL、名前、メモを設定してタイルを作成・編集
- **ファビコン表示** … 登録したサイトのファビコンをタイルに自動表示
- **メモ機能** … 各URLにメモを紐づけて保存
- **表示オプション** … 「タイルに名前を表示」「新しいウィンドウで開く」をチェックで切り替え
- **右クリックメニュー** … タイルを右クリックで詳細（名前・URL・メモ）表示と、編集・削除
- **ローカルストレージ保存** … 登録内容をブラウザに保存し、設定内容を保持

## 使用技術

- **HTML / CSS / JavaScript**（フレームワークを使わない素の実装）
- **Web Storage API（ローカルストレージ）** … データの永続化
- **CSS ネスト記法** … スタイルの構造化・保守性向上

その他：Font Awesome（アイコン）、ress（CSSリセット）

## 工夫した点

### イベント処理とデータ設計の見直し

開発当初は、各タイルの要素一つひとつにイベントリスナーを付け、タイル自体に処理を持たせる書き方をしていました。しかし開発を進める中で、タイル群の親要素にリスナーをまとめて設定し、クリックされたタイルのインデックスを起点に処理を適用する方式（イベント委譲）へと全面的に書き換えました。

「画面から値を受け取る→処理する→結果を画面に返す」という流れを一貫させることで、構造が直感的になり、仕様変更にも強くなりました。特に、ドラッグ&ドロップによるタイルの並び替えは、この設計にしたことで実装が大幅に容易になったと考えています。

### 継続的なリファクタリング

既存の処理にも定期的にリファクタリングを行い、安全かつ容易に仕様変更を行える状態を保つことを意識しています。CSSについても、途中からネスト記法を導入してセレクタの構造を整理し、保守性を高めています。
